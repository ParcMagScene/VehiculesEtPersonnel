# Rapports de contrôles

Les rapports sont classés par année et période de contrôle :

- `2026/04 - Avril` : rapports du lot d'avril 2026.
- `2026/09 - Septembre - Partiel Queen` : rapports partiels de septembre 2026.
- `2026/10 - Octobre - Palans` : rapports d'octobre 2026.
- `Imports/` : nouveaux PDF déposés depuis le module « Contrôles » d'eMag.

Les doublons strictement identiques ont été dédupliqués par empreinte SHA-256 ;
une copie de chaque rapport distinct est conservée. Les différentes versions
(dates ou contenu différents) restent archivées séparément.

Les imports via eMag sont enregistrés et consultables par les utilisateurs
authentifiés. L'import d'un rapport ne met à jour les contrôles qu'après
validation manuelle de la date, du résultat et des équipements proposés.
