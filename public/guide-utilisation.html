Guide d'utilisation rapide
🔗 Accès à l'application
http://votre-serveur:4173

🚀 Démarrage Rapide

1
Accéder à l'application
Ouvrez votre navigateur et allez sur http://votre-serveur:4173
2
Configurer Google Calendar (optionnel)
Cliquez sur l'icône ⚙️ en haut à droite → Onglet "Synchronisation" → Entrez votre Client ID OAuth 2.0
3
Créer votre première réservation
Cliquez sur une cellule du planning → Remplissez le formulaire → Validez
💡 Astuce : Utilisez Cmd+Clic (Mac) ou Ctrl+Clic (Windows) pour sélectionner plusieurs jours d'affilée.

📋 Fonctionnalités Principales

📅 Gestion des Réservations
  • Créer : Cliquez sur une cellule du calendrier
  • Modifier : Cliquez sur une réservation existante
  • Prolonger : Maintenez Shift et cliquez sur les jours suivants
  • Supprimer : Ouvrez la réservation → Bouton "Supprimer"
🚗 Gestion des Véhicules
  • Accès via l'icône ⚙️ → Onglet "Véhicules"
  • Ajouter, modifier, supprimer des véhicules
  • Réorganiser par glisser-déposer
  • Associer une photo au véhicule
  • Voir l'historique des interventions (clic sur le véhicule dans le planning)
🔧 Interventions & Maintenance
  • Programmer : Clic véhicule → "Programmer une intervention"
  • Demander : Clic véhicule → "Demander une intervention"
  • Signaler panne : Clic véhicule → "Signaler une panne"
  • Historique complet des interventions dans la fiche véhicule
👥 Gestion Clients & Conducteurs
  • Gérer depuis ⚙️ → Onglets "Clients" et "Conducteurs"
  • Créer des fiches complètes avec toutes les informations
  • Sélection rapide lors de la création de réservations
📍 Lieux de Retrait/Dépôt
  • Gérer depuis ⚙️ → Onglet "Lieux"
  • Utilisation de Google Maps pour l'autocomplétions
  • Sélection rapide dans les formulaires de réservation
☁️ Synchronisation Google Calendar
  • Configurez via ⚙️ → Onglet "Synchronisation"
  • Les événements Google Calendar s'affichent au-dessus du planning
  • Calendrier partagé : tous les utilisateurs voient les mêmes événements
  • Connexion individuelle avec compte Google

💾 Import / Export de Données

Exporter vos données

1
Cliquez sur ⚙️ → Onglet "Synchronisation"
2
Cliquez sur "Exporter toutes les données"
3
Un fichier JSON sera téléchargé avec toutes vos données

Importer vos données

1
Cliquez sur ⚙️ → Onglet "Synchronisation"
2
Cliquez sur "Importer des données"
3
Sélectionnez votre fichier JSON de sauvegarde
⚠️ Attention : L'import remplace complètement toutes les données actuelles. Exportez d'abord vos données si vous souhaitez les conserver.
✅ Utilisation : Parfait pour transférer vos données entre différents ordinateurs ou navigateurs.

🖥️ Vues du Calendrier

  • Vue Semaine : Affiche 7 jours d'affilée
  • Vue Mois : Affiche le mois complet
  • Vue Année : Vue d'ensemble annuelle
Navigation : Utilisez les flèches ← → pour naviguer, ou cliquez sur "Aujourd'hui" pour revenir à la date actuelle.

🔐 Configuration Google Calendar

Prérequis

1
Créer un projet Google Cloud
Allez sur console.cloud.google.com → Nouveau projet
2
Activer l'API Google Calendar
APIs & Services → Bibliothèque → Recherchez "Google Calendar API" → Activer
3
Créer un Client ID OAuth 2.0
APIs & Services → Identifiants → Créer des identifiants → ID client OAuth
4
Configurer les origines autorisées
Ajoutez : http://votre-serveur:4173
5
Ajouter des utilisateurs de test
OAuth consent screen → Test users → Ajoutez les emails autorisés
6
Créer un calendrier partagé
Google Calendar → Créer un agenda → Partager avec vos collaborateurs
7
Configurer dans l'application
⚙️ → Synchronisation → Collez le Client ID et l'ID du calendrier

❓ FAQ Rapide

Comment accéder depuis un autre ordinateur ?

Sur l'autre ordinateur, modifiez le fichier /etc/hosts (Mac/Linux) ou C:\Windows\System32\drivers\etc\hosts (Windows) et ajoutez :
IP_SERVEUR votre-domaine.example.com

Les réservations importées n'apparaissent pas ?

Assurez-vous d'attendre le message de confirmation complète avant que la page ne se recharge. L'import peut prendre quelques secondes selon le volume de données.

Erreur 404 avec Google Calendar ?

Vérifiez que l'API Google Calendar est bien activée dans votre projet Google Cloud Console. Si vous utilisez un calendrier partagé, assurez-vous que l'ID est correct.

Comment partager le calendrier avec mes collaborateurs ?

L'application utilise IndexedDB (stockage local du navigateur). Pour partager, chaque utilisateur doit accéder à la même URL. Pour un calendrier Google partagé, créez un calendrier dans Google Calendar et partagez-le avec tous les utilisateurs.
