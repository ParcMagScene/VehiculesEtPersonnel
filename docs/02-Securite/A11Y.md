## Règles de codage a11y (à respecter dans les futurs PR)

1. **Tout `<label>`** doit cibler un contrôle via `htmlFor` ou wrapper l'input. Sinon utiliser `<span>` (texte d'affichage) ou `<fieldset><legend>` (groupe de radios/checkboxes).
2. **Toute `<img>` non décorative** doit avoir un `alt` descriptif. Si purement décorative : `alt=""` + `role="presentation"` accepté.
3. **Toute modale** doit utiliser `<Modal>` qui gère `aria-labelledby` automatiquement. Si pas de titre visible, fournir `ariaLabel`.
4. **Tout champ formulaire** doit être enveloppé dans `<FormField>` qui gère `label`, `error`, `hint`, `aria-describedby` et `aria-invalid` automatiquement.
5. **Cibles tactiles** : minimum 44×44 px (vérifier sur mobile).
6. **Contraste couleur** : minimum 4.5:1 pour texte normal, 3:1 pour texte large (à auditer avec Lighthouse).
7. **Focus visible** : ne jamais supprimer `:focus-visible` sans alternative.
8. **`prefers-reduced-motion`** : automatiquement géré par App.css. Pour de nouvelles animations JS, vérifier `window.matchMedia('(prefers-reduced-motion: reduce)').matches`.
